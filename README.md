# 💰 Финансовый учёт — Битрикс24

Приложение для управления финансами в Битрикс24:
импорт/экспорт CSV, отчёты, дашборд с графиками.

---

## 🚀 Установка (пошагово)

### Шаг 1 — Регистрация приложения в Битрикс24

1. Войдите в ваш Битрикс24
2. Слева в меню → **Разработчикам** → **Другое** → **Приложения** → **Добавить**
3. Тип: **"Встраиваемое в левое меню"**
4. Заполните:
   - Название: `Финансовый учёт`
   - URL обработчика: `https://yourapp.epizy.com/index.php`
   - URL установки: `https://yourapp.epizy.com/install.php`
5. Нажмите **Сохранить** → скопируйте `Client ID` и `Client Secret`

---

### Шаг 2 — Хостинг (бесплатно на InfinityFree)

1. Зарегистрируйтесь на **infinityfree.com**
2. Создайте аккаунт → выберите домен вида `yourapp.epizy.com`
3. В VistaPanel запишите данные MySQL:
   - Host, DB Name, DB User, DB Password

---

### Шаг 3 — База данных

1. VistaPanel → **MySQL Databases** → создайте БД
2. Откройте **phpMyAdmin**
3. Выберите вашу БД → вкладка **SQL**
4. Вставьте содержимое файла `sql/schema.sql` → Выполнить

---

### Шаг 4 — Настройка config.php

Откройте файл `config.php` и заполните:

```php
define('CLIENT_ID',     'ваш_client_id');
define('CLIENT_SECRET', 'ваш_client_secret');
define('APP_URL',       'https://yourapp.epizy.com');

define('DB_HOST', 'sql200.epizy.com');   // из VistaPanel
define('DB_NAME', 'epiz_XXXXX_finance'); // ваша БД
define('DB_USER', 'epiz_XXXXX');         // ваш пользователь
define('DB_PASS', 'ваш_пароль');
```

---

### Шаг 5 — Загрузка файлов

1. В VistaPanel → **File Manager** → папка `htdocs`
2. Загрузите все файлы проекта (кроме папки `sql`)
   - ИЛИ через FTP (данные в VistaPanel → FTP Accounts)

Итоговая структура на хостинге:
```
htdocs/
  index.php
  install.php
  config.php
  assets/
  src/
  templates/
  uploads/
```

---

### Шаг 6 — Установка

1. В Битрикс24 откройте ваше приложение
2. Нажмите кнопку установки
3. Разрешите доступ → приложение готово!

---

## 📋 Функциональность

| Раздел     | Возможности |
|------------|-------------|
| Дашборд    | Итоги за год, график по месяцам, расходы по категориям, остатки по счетам |
| Платежи    | Список с фильтрами (дата, тип, счёт, категория), удаление |
| Добавить   | Приход/расход вручную, категория, счёт, компания, комментарий |
| Импорт     | Загрузка CSV (UTF-8 или Windows-1251), шаблон для скачивания, история импортов |
| Отчёты     | Сводный / детальный / по категориям, экспорт CSV, печать/PDF |
| Настройки  | Управление счетами и категориями |

---

## 📥 Формат CSV для импорта

```
date;type;amount;company;category;account;comment
01.05.2026;income;50000;ООО Клиент;Продажи;Касса 1;Договор №1
02.05.2026;expense;12000;ИП Иванов;Зарплата;Касса 1;ЗП апрель
```

Поддерживаемые форматы дат: `DD.MM.YYYY`, `YYYY-MM-DD`, `DD/MM/YYYY`
